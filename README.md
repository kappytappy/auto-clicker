# Auto Clicker

A tiny Windows app that clicks wherever your cursor is, as fast as you tell it to. No install, no setup — download one exe and double-click.

## How to use

1. Download `auto-clicker.exe` from the [Releases page](../../releases).
2. Set how often it clicks (milliseconds) and which mouse button.
3. Hit **START** — or press **F6** anywhere, even with the window in the background.
4. Press **F6** or **STOP** to stop.

Handy for grinding through repetitive clicking in games, forms, or testing. It never moves your mouse — it just clicks where you left the cursor.
